# Security Policy

## Supported versions

The project is currently in pre-1.0 development. Security fixes are prioritized for the main branch and the next release line.

## Reporting a vulnerability

Please report security issues privately via the maintainer contact channel. Do not open a public issue for undisclosed vulnerabilities.

## Security principles

- Local-first data storage
- Localhost-only backend binding
- Secret handling via OS credential storage
- Redaction of secrets in logs
- No blanket file system or shell permissions in desktop integration
